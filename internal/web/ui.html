Layout

Drag a panel to move it. Drag its bottom-right corner to resize. Click one to change its settings.

Calendars

Each calendar you add shows up on the mirror in its own colour. You can choose which panels show which calendars in the Layout tab.

General

Where the mirror is, and what to call it.

Location & time

Used for the weather and for showing the right local time.

A postcode or a town name — either works.

Software updates

The mirror installs new versions on its own. If a new version fails to start, it puts the previous one back.

Released versions is what you want on a mirror you rely on. Test versions takes new builds before they are released, to try them out before everyone else gets them — expect the occasional rough edge. Switching back brings this mirror to the released version.

Network name

What to type in a browser to reach this page.

The mirror answers to magicmirror.local on your home network. Letters, numbers and hyphens only.
